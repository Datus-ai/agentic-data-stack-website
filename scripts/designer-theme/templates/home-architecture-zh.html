WHAT IS AGENTIC DATA STACK?

当 Agent 成为数据系统的使用者与建设者。

Agentic Data Stack 指面向 AI Agent 设计和演进的数据技术栈，使 Agent 能够理解数据与业务上下文，并在受治理、可验证的条件下完成数据发现、开发、分析和运维等任务。

Modern Data Stack 围绕人的工作方式构建。Agent 时代既需要更强大的 Data Agent，也需要重新思考数据基础设施的架构与设计。
